# A Random Draw Programme



#### 中文：

#### 这个程序是在旧版的基础上重写了一遍抽签的实现，悬浮窗部分由AI完成这样比较快，

#### 这里只说明导入文件

#### 文件中写权重可以通过该格式 \[权重],\[元素] 不写默认为1。

#### 什么意思呢例如文件*Text.txt:*

#### ------------------------------------

#### 1,a

#### 2,o

#### e

#### i

#### 1,u

#### ------------------------------------

#### 此时我导入后会产生 权重为1,内容为A的一行

#### 权重为2,内容为I的一行

#### 权重为1,内容为U的一行

#### ....



#### 日本語：

#### このソフトウェアは　ザ古いバージョンから　あらためた、フロートは　エーアイに　完成された

#### 以降は　ファイルを引き込むことの説明：

#### 

#### 重率の設定は このフォマード\[重率],\[要素]、重率を　無いなら　ディフォルトは１。

#### 例えファイル*Text.txt:*

#### ------------------------------------

#### 1,あ

#### 2,い

#### う

#### え

#### 1,お

#### ------------------------------------

#### 引き込ん後で 重率は「１」と要素は「あ」をクリエイトした

#### 重率は「２」と要素は「い」

#### 重率は「１」と要素は「う」

．．．

#### This Programme was finished from the old version, The floatingwindow was completed by AI.
